## 🏗️ No que tenho trabalhado:
- **Bots de WhatsApp (BLiP SDK):** Desenvolvimento e manutenção de chatbots de atendimento para o setor de saúde, com fluxos de agendamento, financeiro e integração com sistemas legados (ERP/API do plano de saúde).
- **Verificação de identidade (Biometria facial):** Implementação ponta a ponta de um fluxo seguro de verificação facial — tela web com captura ao vivo pela câmera (sem upload de arquivo), integração com API de biometria de terceiros, e sincronização assíncrona entre o bot de WhatsApp e o painel web via banco de dados compartilhado.
- **Dashboards & Gestão (Jira):** Desenvolvimento e deploy na AWS de dashboard para métricas de produtividade, integrando APIs do Jira com visualizações gráficas.
- **Painéis administrativos (Next.js):** Construção de dashboards internos de relatórios, gestão de usuários com controle de permissões, e configuração operacional (horários de atendimento, feriados) refletida em tempo real nos bots em produção.
- **Infraestrutura & Deploy:** Empacotamento de aplicações em Docker (multi-stage build), orquestração de múltiplos serviços via Docker Compose, deploy em Portainer atrás de proxy reverso (Traefik) com HTTPS automático, e pipelines de CI/CD no GitLab para build e publicação de imagens.
- **SaaS & Telemedicina:** Implementação de infraestrutura de videoconferência (Jitsi) via Docker na AWS para o setor de saúde.
- **Modernização de Layouts:** Redesign de portais legados para layouts "Premium", focando em interfaces modernas e intuitivas.
